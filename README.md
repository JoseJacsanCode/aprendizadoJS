# aprendizadoJS 📚

Repositório com meus estudos e exercícios práticos de **JavaScript puro (vanilla JS)**, feito para consolidar os fundamentos da linguagem através de pequenos scripts, manipulação do DOM e interação com o usuário.

## 📖 Sobre o projeto

Este repositório reúne uma sequência de exercícios organizados por tema, indo desde os primeiros comandos em JavaScript até estruturas condicionais e manipulação de eventos no navegador. Cada pasta representa uma etapa do aprendizado, com arquivos HTML, CSS e JS integrados.

## 🗂️ Estrutura do repositório

| Pasta | Conteúdo |
|---|---|
| `Primeiros_Scripts/` | Primeiro contato com JavaScript: `alert()`, `confirm()` e `prompt()` |
| `Trabalhando_com_DOM/` | Seleção de elementos do DOM (`getElementById`, `getElementsByTagName`, `getElementsByName`, `querySelector`) e manipulação de estilo/conteúdo |
| `Tratando_dados/` | Captura de dados do usuário, conversão de tipos (`Number()`), template literals e métodos de string (`toUpperCase`, `toLowerCase`, `length`) |
| `Eventos_DOM/` | Eventos do DOM com `addEventListener` (`click`, `mouseenter`, `mouseout`) e uma calculadora simples de soma |
| `Condicionais/` | Estruturas condicionais simples (`if`) |
| `Condicionais - parte 2/` | Condicionais mais completas: `if / else if / else`, `switch/case`, exemplos com data/hora e verificação de idade |
| `exercicios/` | Exercícios práticos gerais, incluindo uma subpasta `condicionais/` com exercícios adicionais sobre o tema |

## 🚀 Tecnologias utilizadas

- **JavaScript** — lógica e interatividade
- **HTML5** — estrutura das páginas
- **CSS3** — estilização básica

## 📚 Tópicos estudados

- Comandos de interação: `alert`, `confirm`, `prompt`
- Manipulação do DOM (seleção e alteração de elementos)
- Eventos de mouse e clique
- Conversão e tratamento de dados (`Number`, template strings)
- Métodos de string
- Estruturas condicionais (`if/else`, `switch`)
- Pequenos projetos práticos (calculadora, verificação de nacionalidade, verificação de idade/voto)

## ▶️ Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/JoseJacsanCode/aprendizadoJS.git
   ```
2. Entre na pasta do exercício desejado.
3. Abra o arquivo `.html` correspondente diretamente no navegador (duplo clique ou usando a extensão **Live Server** no VS Code).
